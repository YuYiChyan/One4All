# MAONO PD100X（352F:010C）

本适配只对应已连接的 **PD100X Podcast Microphone，VID 352F / PID 010C**。不将 PD100X RGB（0108）、Lite（0109）或 PD200X 自动列为兼容。控制通过 USB HID 输入/输出报告直连，**不需要 MAONO Link 常驻**。原厂程序未安装或启动。

## 原厂来源与拆包

- 官方下载页：[MAONO Download Center](https://www.maono.com/pages/maono-software-download-center)。
- 本次原包：[Maono Link V4.8.3_1106.exe](https://update.maono.com/MaonoLink/Maono%20Link_V4.8.3_1106.exe)，379,190,576 字节，SHA-256 `7621c2b7ff8e1cdf7826a197c2fc9e27ea29484260e2edc5fb65b40455036611`。
- `MaonoDevicesInfo.txt` 明确 `pid_010C:PD100X,PD100X,PD100X.dll,0`。下列协议证据来自这个 DLL，而不是其他型号的开源实现。
- 模块导出的是 Qt 窗口工厂和 UI 事件接口；One4All 不载入这套窗口模块。协议编码由静态反汇编独立转写，不复制原厂可执行代码。
- 原厂图取自 `PD100X.dll` 的 Qt 资源 `:/Images/left/PD100X_New.png`，1689×1689 透明 PNG。资源注册调用 RVA `0x114E`、图片数据 RVA `0x1CC66D`，733,460 字节。仅提供黑色机身图；灯光颜色不是商品配色版本。

## 实物接口与帧

Windows 只读元数据确认：MI_03，顶层 Usage Page `0x000C` / Usage `0x0001`，输入与输出最大长度均为 **64 字节（含报告 ID）**，无 Feature Report。厂商输出 Report ID 为 `0x4B`，63 字节载荷；原厂 DLL 内部的 65 字节 QByteArray 不代表本设备报告长度。

| 字段 | 位置/内容 |
| --- | --- |
| Report ID / 帧头 | byte 0=`4B`，byte 1=`C4` |
| 有效长度 | uint16 LE@2；包含从 byte 1 到校验末尾的字节数 |
| 命令 | byte 5：`04` 单寄存器查询，`03` 设置/主动上报 |
| 寄存器地址 | uint16 LE@6 |
| 查询回应或设置值 | uint16 LE@8 |
| 校验 | 查询包 LE@8、带值包 LE@10；`-sum(bytes[1:checksumOffset]) & 0xFFFF` |
| 填充 | 补零至 64 字节 |

原厂 `PD100X.dll` 的 RVA `0x1B2B0` 构造单寄存器查询（`kind=04`），`0x1B360` 构造单寄存器设置（`kind=03`），`0x1B1D0` 为校验算法。查询增益的实际输出前缀为 `4B C4 09 00 00 04 23 20 EC FE`；实物回应前缀 `4B C4 0B 00 00 04 23 20 60 00 8A FE`，增益值 96。

设备会夹送 `kind=03 / address=2034` 的电平上报。**读取必须同时匹配 `kind=04` 和请求地址**，不能将下一条任意报告当作查询回应或设置成功。设置流程需再次查询对应寄存器并核对写入值。

## 已实现字段

下列 RVA 均属于本包 `PD100X.dll`。单位沿用控制值，不把数字增益擅自解释为声学 dB。

| 控件 | 寄存器 | 编码/范围 | 原厂证据 |
| --- | --- | --- | --- |
| 麦克风增益 | `2023` | 0–100，整数 | `144EA–144F2` 滑块上限100；`15725–1574B` 原值写入 |
| 麦克风静音 | `2022` | 0关、1开 | `413D–4150` 构包；接收分支 `1EAA3` 邻近处理 |
| 降噪开关 | `203A` | 0关、1开 | `15AE4–15B58` 原厂开关与反向禁用框 |
| 降噪强度 | `203B` | 控件0–40；原始值=`1200 + 10 × 控件值` | `144C7` 上限40；`156D8–15709` 编码；`15978–15995` 回读还原 |
| 灯光开关 | `2036` | 0关、1开 | `19D00–19E0E` |
| 灯光亮度 | `2037` | 0–100 | `18A1D–18A38` 范围；`19240` 写入 |
| 灯效 | `2038` | 常亮高半字节0，呼吸高半字节1（`10`十六进制） | `16DB8` 常亮；`19570` 颜色值加`10` |
